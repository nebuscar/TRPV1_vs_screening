# TRPV1_vs_screening

Reproducible scripts and configuration for TRPV1-focused virtual screening.

########## 0. contents ##########

- `configs/`: target definitions, screening parameters, and environment files.
- `scripts/`: ordered data acquisition and analysis scripts.
- `reports/`: compact tabular result summaries used by the report.

########## 1. figures ##########

Project figures are stored separately in `nebuscar/imagestore` under `TRPV1_vs_screening/`.
